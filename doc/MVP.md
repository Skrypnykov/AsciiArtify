# MVP Deployment: AsciiArtify

## Мета

Після успішного налаштування ArgoCD, запустити повний цикл, та продемонструвати, як ArgoCD автоматично відслідковує та синхронізує зміни з Git репозиторію та розгортає їх на Kubernetes кластері.

---

## Інфраструктура

* **Kubernetes кластер:** локальний кластер, створений за допомогою `k3d`
* **GitOps система:** ArgoCD
* **Репозиторій додатку:** [go-demo-app](https://github.com/den-vasyliev/go-demo-app)

---

## Налаштування ArgoCD

1. **Встановлено ArgoCD у кластер:**
   ```bash
   kubectl create namespace argocd
   kubectl apply -n argocd --server-side --force-conflicts -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml
   ```

2. **Налаштовано доступ до GUI через портфорвардинг:**
   ```bash
   kubectl port-forward svc/argocd-server -n argocd 8080:443
   ```

3. **Отримано пароль адміністратора для входу:**
   ```bash
   kubectl get secret argocd-initial-admin-secret -n argocd -o jsonpath="{.data.password}" | base64 --decode
   ```

4. **Створено додаток `AsciiArtify` в ArgoCD з такими параметрами:**
   * **Source:** Git-репозиторій `go-demo-app`
   * **Destination:** локальний кластер, namespace `argocd`
   * **Sync Policy:** автоматична синхронізація *(увімкнено автоматичне створення namespace)*

---

## Автоматична синхронізація

* ArgoCD автоматично відстежує зміни в Git-репозиторії.
* При зміні Helm-чарту (наприклад, типу сервісу або версії додатку) ArgoCD самостійно синхронізує стан у кластері.
* Оновлення додатку відбувається без ручного втручання.
